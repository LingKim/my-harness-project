## ADDED Requirements

### Requirement: 前端提供完整的静态质量门禁

前端工程 MUST 提供 lint、TypeScript 类型检查和自动化单元测试命令，且应用代码与测试代码都 MUST 被 TypeScript 校验；测试框架 API MUST 通过显式模块导入或等价的隔离配置获得类型，不得依赖应用全局中未声明的测试变量。

#### Scenario: 执行前端静态验证
- **WHEN** 开发者在依赖安装完成的前端工程中依次运行 lint、类型检查和单元测试命令
- **THEN** 三个命令均以成功状态退出
- **AND** 类型检查覆盖应用代码和测试代码

#### Scenario: 测试文件出现类型错误
- **WHEN** 测试文件引用不存在的变量或以错误类型调用组件
- **THEN** TypeScript 类型检查以失败状态退出
- **AND** 不会因为测试文件被排除或测试全局被错误忽略而漏报

#### Scenario: Harness 检查当前前端门禁
- **WHEN** 开发者运行根级 Harness 检查
- **THEN** Harness 校验当前单元测试入口、Playwright 配置、E2E 目录、类型检查脚本和 E2E 脚本存在
- **AND** Harness 不再依赖已经被双语 App Router 替代的旧根页面测试路径

### Requirement: 产品页面使用稳定的双语 URL

前端 SHALL 使用 `/en` 和 `/zh-CN` locale 子路径提供英文与简体中文页面。根路径或缺少 locale 的产品路径 MUST 按“用户已保存选择、浏览器语言、默认英文”的顺序选择受支持 locale；未知 locale MUST 返回 404，不得静默渲染其他语言。

#### Scenario: 中文浏览器首次访问根路径
- **WHEN** 没有已保存语言选择且浏览器明确偏好中文的访客访问根路径
- **THEN** 前端将访客导航到 `/zh-CN`

#### Scenario: 非中文浏览器首次访问根路径
- **WHEN** 没有已保存语言选择且浏览器不偏好中文的访客访问根路径
- **THEN** 前端将访客导航到 `/en`

#### Scenario: 已保存选择覆盖浏览器语言
- **WHEN** 用户已主动选择英文但浏览器偏好中文
- **THEN** 用户后续访问缺少 locale 的产品路径时进入对应英文路径

#### Scenario: 访问未知 locale
- **WHEN** 访客访问以不受支持 locale 开头的产品路径
- **THEN** 前端返回 404 页面
- **AND** 不把该 locale 静默替换成英文或中文

### Requirement: 语言切换保留当前导航上下文

全局导航 SHALL 始终提供中英文切换入口。用户切换语言后 MUST 保留当前产品页面路径、查询参数和 URL 片段，并 MUST 保存本次非敏感语言选择供后续访问使用；当前页面的导航、标题、按钮、状态和系统提示 MUST 使用目标语言。

#### Scenario: 在功能路径切换语言
- **WHEN** 用户在 `/en/guides?city=shanghai#results` 切换为简体中文
- **THEN** 前端导航到 `/zh-CN/guides?city=shanghai#results`
- **AND** 页面公共文案使用简体中文

#### Scenario: 刷新已切换页面
- **WHEN** 用户主动切换语言后刷新页面或重新访问缺少 locale 的路径
- **THEN** 前端继续优先使用用户最近选择的语言

### Requirement: 双语文案默认在服务端加载

前端 MUST 为英文和简体中文维护独立、类型可校验的文案资源，并 SHALL 在 Server Component 中按 locale 加载页面所需文案。传入 Client Component 的数据 MUST 限制为该组件实际使用的最小字段，不得把完整文案字典无条件序列化到浏览器。

#### Scenario: 服务端渲染双语首页
- **WHEN** 分别请求 `/en` 与 `/zh-CN`
- **THEN** 服务端输出对应语言的首页标题、导航和主要操作文案
- **AND** 客户端包不包含另一种语言的完整首页字典

#### Scenario: 文案键在一种语言中缺失
- **WHEN** 开发者新增公共文案键但只在一种语言资源中提供
- **THEN** 类型检查或自动化测试失败并定位缺失的文案键

### Requirement: 全局产品框架提供稳定导航

每个受支持 locale 下的产品页面 SHALL 提供 ChinaMate 品牌入口、Home、Ask AI、Guides、Community、语言切换和账号入口，并 SHALL 提供包含产品信息、隐私政策、服务条款和联系入口的页脚。尚未实现的业务路由 MUST 显示明确的开发中状态，不得伪装成可用功能或连接伪 API。

#### Scenario: 访问任一产品页面
- **WHEN** 用户访问任一受支持 locale 下的产品页面
- **THEN** 页面展示语义明确且可通过键盘操作的全局导航
- **AND** 品牌入口可以返回当前语言首页
- **AND** 页脚展示当前语言的必要产品入口

#### Scenario: 访问尚未实现的业务路由
- **WHEN** 用户通过全局导航进入尚未开发的攻略、AI、社区或账号页面
- **THEN** 页面显示当前语言的功能开发中状态
- **AND** 页面不展示虚假的业务数据或可提交操作

### Requirement: 首页提供最小产品价值壳层

双语首页 SHALL 展示 ChinaMate 产品定位、AI 提问入口、主要行动按钮、支付/上网/交通/购票/点餐/问路六类核心场景和可信度说明。AI 提问入口在本变更中 MUST 明确为后续功能入口，不得向未实现接口提交数据。

#### Scenario: 在核心 PC 视口访问首页
- **WHEN** 用户以 1920×1080 视口访问任一语言首页
- **THEN** 无需向下滚动即可看到产品定位、AI 提问入口和主要行动按钮
- **AND** 页面没有横向滚动条

#### Scenario: 激活尚未实现的 AI 入口
- **WHEN** 用户激活首页 AI 提问入口或主要 AI 行动按钮
- **THEN** 前端进入当前语言的 AI 功能开发中页面
- **AND** 不会丢失当前 locale

### Requirement: 前端提供一致的通用页面状态

前端 SHALL 提供双语的加载、空内容、预期错误、未知错误、404、无权限和功能开发中状态。状态 MUST 使用语义化标题与说明，关键含义不得只依靠颜色表达；可恢复错误 MUST 提供明确的重试或返回操作。

#### Scenario: 页面路由不存在
- **WHEN** 用户访问受支持 locale 下不存在的页面
- **THEN** 前端显示当前语言的 404 状态
- **AND** 提供返回当前语言首页的操作

#### Scenario: 用户无权访问页面
- **WHEN** 后续功能使用公共无权限状态展示访问拒绝
- **THEN** 状态明确说明无法访问
- **AND** 提供安全的返回操作
- **AND** 不展示受保护内容

#### Scenario: 可恢复加载失败
- **WHEN** 后续页面使用公共错误状态表示可重试失败
- **THEN** 状态同时展示文本说明和可聚焦的重试操作
- **AND** 不只使用颜色或图标表达失败

### Requirement: PC 布局满足首发视口基线

前端 SHALL 使用最大宽度 1440px 的居中内容容器和适合 PC 的页面结构。1920×1080 与 1440×900 视口 MUST 不出现主要内容遮挡、横向溢出或关键操作不可见；低于 1280px 时 MUST 提供基础可访问页面和明确的小屏降级提示，但不要求完整移动端适配。

#### Scenario: 在两个 PC 视口访问产品页面
- **WHEN** 浏览器分别以 1920×1080 和 1440×900 访问首页及导航目标页
- **THEN** 页面没有横向溢出或主要内容遮挡
- **AND** 全局导航与主要操作保持可见和可操作

#### Scenario: 使用小屏访问
- **WHEN** 浏览器宽度低于 1280px
- **THEN** 页面仍可读取核心内容并进行基础导航
- **AND** 页面明确提示 PC 端体验优先

### Requirement: 浏览器 E2E 验证关键底座行为

前端 MUST 提供可重复执行的真实浏览器 E2E 命令，覆盖根路径语言处理、双语页面直达、语言切换、未知 locale、全局导航、首页首屏、目标 PC 视口和小屏降级。E2E MUST 使用独立开发端口，不得依赖已经手工启动的服务或真实后端。

#### Scenario: 从干净环境执行 E2E
- **WHEN** 开发者已安装项目声明的浏览器运行时并执行前端 E2E 命令
- **THEN** 测试自动启动并停止独立前端服务
- **AND** 测试不访问真实后端、数据库或 AI 服务
- **AND** 所有底座验收场景通过

#### Scenario: 浏览器运行时尚未安装
- **WHEN** 开发者未安装项目声明的浏览器运行时便执行 E2E
- **THEN** 工程文档提供明确的安装命令
- **AND** 不要求安装与本项目无关的浏览器引擎
