## Why

ChinaMate 当前账号入口仍是占位页面，后端 `account` 模块也没有可用的身份认证能力，用户无法跨设备保存攻略、AI 对话和社区进度。首个业务模块需要以最少个人信息完成账号注册、登录和稳定会话，并把 Pencil 登录/注册设计稿转化为可验证的前后端合同。

## What Changes

- 按 Pencil 设计节点 `ay6XZ`（登录页）和 `kAJhd`（注册页）交付简体中文与英文登录、注册页面及其交互状态。
- 支持仅使用账号和密码注册；账号为 4—20 位字母、数字或下划线，忽略英文字母大小写且注册后不可修改；密码为 8—64 位并同时包含字母和数字。
- 注册要求确认密码并同意《服务条款》和《隐私政策》，成功后自动登录并安全返回触发认证前的站内页面。
- 支持登录、退出、获取当前账号和页面刷新后的会话恢复；不把访问令牌或刷新令牌暴露给浏览器 JavaScript。
- 采用双 Token 会话：短 Token 有效期 30 分钟，长 Token 有效期 7 天；使用长 Token 刷新时轮换并作废旧 Token，检测重放时撤销对应会话。
- 对账号和 IP 分别实施连续登录失败限制：账号 15 分钟内失败 5 次或 IP 15 分钟内失败 20 次后限制 15 分钟，并返回不泄露账号存在性的统一错误与剩余等待时间。
- 新增后端账号、会话与登录失败状态的数据库结构、HTTP API、安全日志和自动化测试，并新增前端组件、API 适配、表单校验和浏览器验收。
- 本次不提供邮箱、手机号、验证码、第三方登录、“记住我”、未登录找回密码、修改密码、账号修改、公开展示名称维护或管理端账号治理。

可衡量的验收结果：注册、登录、自动刷新、退出、会话恢复、登录失败限制和安全返回均有自动化测试；登录与注册真实页面在桌面和移动端可完成键盘操作；响应、日志、异常、埋点与测试快照不包含密码、密码摘要或原始 Token。

## Capabilities

### New Capabilities

- `frontend-account-authentication`: 登录与注册页面、表单和错误状态、双 Token 会话的浏览器侧协作、认证前后导航、国际化、响应式与可访问性。
- `backend-account-authentication`: 账号注册、登录、双 Token 签发与轮换、当前账号、退出、登录失败限制、持久化和安全边界。

### Modified Capabilities

无。

## Impact

- 主仓库：新增跨仓库 OpenSpec artifacts、交付证据和后续 submodule gitlink 更新。
- `frontend/`：替换 `src/app/[locale]/account/page.tsx` 占位页，新增认证路由/组件/API 客户端/状态与测试，并调整全局账号入口和国际化文案。
- `backend/`：在 `account` 模块新增 API、应用、领域和基础设施代码，增加 Spring Security、Token/Cookie 配置、MyBatis-Plus 持久化、Flyway migration 及分层测试。
- HTTP API：新增账号、认证会话、Token 刷新、退出、CSRF Token 与当前账号契约；错误继续使用项目统一的 `application/problem+json`。
- 数据与安全：新增账号、刷新会话和登录失败限制数据；密码只保存自适应单向摘要，原始 Token 不落库。
- 风险：跨站请求伪造、Token 窃取与重放、开放重定向、账号枚举、暴力破解、Cookie 跨域配置和多节点限流一致性，需要在设计与专项测试中关闭。
