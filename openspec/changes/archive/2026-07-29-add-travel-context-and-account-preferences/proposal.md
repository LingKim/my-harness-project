## Why

ChinaMate 已具备账号注册、登录和会话能力，但登录用户还无法持久化旅行上下文与界面语言偏好，也没有受保护的修改密码路径。补齐这组 P0 能力，才能让回答使用用户主动提供的限制、让双语体验跨登录保持，并让账号持有人在不引入额外身份资料的前提下维护凭据。

## What Changes

### 目标

- 为登录账号提供旅行上下文的查询、更新与整组清空能力；除界面语言外，国籍或常住国家/地区、当前或计划访问城市、旅行日期、饮食禁忌和过敏原、无障碍或其他帮助需求均可不填写。
- 将登录用户主动选择的简体中文或英文同步为账号偏好；切换语言时保留当前页面、搜索条件和未提交表单，刷新或重新登录后继续使用最近一次账号偏好。
- 提供仅限登录用户的修改密码能力，验证当前密码并复用注册密码规则，以统一安全错误响应避免泄露内部校验结果。
- 以 Pencil 节点 `x09Kjg`、`hNTEF`、`O4byu2`、`Hk4TW`、`a8FkLf`、`G1HPz` 为桌面交互基准，覆盖旅行上下文、账号与安全、修改密码及其校验/网络错误状态。
- 冻结账号数据隔离、HTTP API、数据库约束、CSRF/认证权限、统一异常和跨栈测试边界。

### 非目标

- 不收集或新增邮箱、手机号、验证码、第三方登录、头像、公开社交资料。
- 不提供未登录状态的密码找回，也不建设多设备会话查看、逐设备管理或批量会话管理界面。
- 不采集 GPS、实时坐标或其他精确定位；城市仅来自用户主动选择。
- 不在本 change 中实现 AI 回答能力；仅保存后续能力可读取的账号级旅行上下文，并约束未来 AI 使用个人限制时必须明确说明所采用限制。

### 可衡量验收结果

- 账号 A 只能查询、修改和清空账号 A 的旅行上下文；账号 B 与匿名请求不能读取或影响账号 A 数据。
- 六类旅行上下文字段具有明确可选性、校验和清空语义；结束日期早于开始日期时中英文界面均阻止保存并给出可行动提示。
- 登录用户从任意受支持页面切换语言后，路由仍对应同一页面，搜索条件与未提交表单内容保持，账号偏好成功同步；同步失败时不丢失当前页面或表单。
- 修改密码必须同时提交当前密码、新密码和确认密码；当前密码错误、新密码非法或确认不一致使用统一公开失败合同，成功后不返回或记录任何密码。
- 所有新增或变更 API 使用认证上下文确定账号、使用 CSRF 防护处理状态变更，并以 `application/problem+json` 返回稳定错误码。
- 前后端自动化测试覆盖成功、校验失败、认证/权限、网络失败、并发或事务边界、账号数据隔离和中英文交互。

### 已确认决策

- **修改密码后的会话策略**：修改密码成功后立即撤销该账号的其他全部活动会话；轮换并保留当前会话的短 Token、长 Token 与 CSRF Cookie，旧 Token 立即作废，且不延长当前会话原有的 7 天绝对期限。前端保持当前设备登录，并提示其他设备需要重新登录。

## Capabilities

### New Capabilities

- `backend-account-preferences`: 账号级旅行上下文与界面语言偏好的查询、更新、清空、数据隔离、持久化和 API 合同。
- `frontend-account-settings`: 旅行上下文、账号与安全页面及全局语言切换的路由保持、表单状态、错误反馈、国际化和无障碍行为。

### Modified Capabilities

- `backend-account-authentication`: 增加登录状态修改密码、当前密码验证、密码规则、统一安全错误及成功后的会话轮换与撤销合同。
- `frontend-account-authentication`: 增加修改密码页面、客户端校验、安全错误呈现和成功后会话状态处理。

## Impact

- `frontend/`：新增或扩展 `/{locale}/account` 下的设置路由、旅行上下文与修改密码表单、全局 locale 切换和对应 Vitest/Playwright 测试。
- `backend/`：扩展 `account` 模块 API、application、domain 与 infrastructure；新增 Flyway migration、MyBatis-Plus Mapper/XML、事务和 MySQL 集成测试。
- API：计划新增当前账号旅行上下文查询/更新/清空、账号偏好更新与修改密码端点；所有状态变更沿用现有 Cookie 会话和 CSRF 合同。
- 数据：新增账号一对一偏好/旅行上下文持久化结构及多值限制结构或等价规范化模型；不得保存密码明文、精确位置或超出范围的个人资料。
- 风险：旅行限制属于敏感个人信息，需要最小化采集、账号级隔离和安全日志；语言切换可能丢失客户端草稿；修改密码后的会话轮换、其他会话撤销和原绝对期限保持必须原子一致。
