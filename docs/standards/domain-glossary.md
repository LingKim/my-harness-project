# ChinaMate 领域术语桥

本文件把产品语言映射为稳定工程含义，避免 AI 仅凭相似词扩大范围。最终代码位置仍需通过当前规格、源码和测试确认。

| 产品术语 | 工程含义 | 不等同于 | 权威来源 |
| --- | --- | --- | --- |
| 账号 | 用户身份、凭据、会话及账号级偏好集合，归属 `account` | 单个浏览器 Cookie 或旅行上下文 | `PRD:FR-AUTH-001—003`、后端模块地图 |
| 旅行上下文 | 用户可选的来华时间、城市、语言等辅助信息，归属账号模块 | HTTP Session、AI 会话或强制注册字段 | `PRD:FR-AUTH-003` |
| 结构化攻略 | 具有双语版本、步骤、来源、验证时间、状态和备用方案的受治理内容 | 普通博客、AI 即时回答或社区帖子 | `PRD:FR-GUIDE-001—004` |
| AI 会话 | 用户与 AI 助手的一组消息、引用、风险和反馈上下文，归属 `assistant` | 登录会话、社区问题或永久知识源 | `PRD:FR-AI-001—007` |
| 知识引用 | AI 回答中可追溯到已允许知识内容的来源信息 | 任意外链、模型训练数据声明或无依据文本 | MVP 计划 M05、AI 设计待办 |
| 社区已解决 | 社区问题根据已确认规则达到解决状态，通常关联最佳回答或明确关闭动作 | 仅有回答、AI 判定正确或内容被隐藏 | `PRD:FR-COM-001—005` |
| 高风险升级 | 医疗、法律、人身、过敏、金融等场景进入受控提示或人工/官方渠道 | 让模型重试、生成更长答案或自动保证正确 | MVP 计划 M05-D05 |
| AI 转社区 | `support` 编排允许公开的 AI 会话摘要，创建待用户确认的社区问题草稿 | `assistant` 直接写社区表或自动公开聊天内容 | 后端模块地图跨模块协作 |
| 功能开发中 | 路由和页面框架已存在，但真实业务、API 或数据尚未交付 | 功能已完成、可调用伪 API 或可以计入业务验收 | `SPEC:frontend-development-foundation` |

## 使用约束

- 需求中的触发点、拦截、权限和失败行为必须引用 PRD、Spec、设计节点或用户原话。
- 发现相似入口但没有来源时，标记为待确认或非目标。
- 术语含义变化属于产品或架构合同变化，先通过 OpenSpec 更新本文件及相关规格。
